Raphael: Great Coding Sage

An AI coding agent inspired by Raphael — the Great Sage.

Raphael is a command-line AI coding agent built to assist with writing, understanding, debugging, and improving code directly from the terminal.

🚧 Status: Raphael is currently in the initial development phase. The project is actively evolving, and features may change frequently.

Features
- AI-powered coding assistance
- Terminal-first experience
- Code generation and understanding
- Debugging assistance
- LLM integration

More features coming soon.
